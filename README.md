# bio

The assets of my profile bio. GitHub Pages serves them at https://rodbove.github.io/bio/.

- `snippet.html`: the HTML and CSS to paste into the bio. It has no scripts.
- `index.html`: a page that shows the snippet.
- `car.png`: an animated PNG of a car from my game, the-scene.
- `sounds/`: the drum sounds of the pads, made with [flip](https://github.com/rodbove/flip).

## How the pads play

Each pad holds copies of the browser audio player. The players are invisible and cover the full pad. A player that plays lets clicks go through to the next copy, so fast hits do not stop.
